Contact PDF Engine

We welcome bug reports, accessibility feedback, and suggestions for new tools or improvements.

PDF Engine is a browser-based online service, not downloadable desktop software. Any files downloaded from the tools are generated or processed document/image outputs—not software installers. The site does not distribute a desktop application, installer, browser extension, or plugin.

Support and feedback

Use the project's public GitHub issue tracker to describe the issue, the tool you were using, your browser, and the steps needed to reproduce the problem.

Open a PDF Engine support issue on GitHub →

Privacy note: Do not upload or attach confidential PDFs, identification documents, passwords, or private personal information to a public issue. If you report a processing bug, use a non-sensitive sample file.
