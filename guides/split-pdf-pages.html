How to Split PDF Pages

Splitting a PDF helps when you need only a few pages from a long report, want to share one invoice, or need each page as its own document. First decide whether you need a selection of pages or a separate file for every page.

Choose the right split method

  • Extract selected pages: best for a chapter, receipt, signed page or a small group of pages.
  • Separate every page: useful when each page must be delivered independently. The tool packages the results into a ZIP file.

Extract a selection

  1. Open the Split PDF tool.
  2. Choose the source PDF from your device.
  3. Enter page ranges such as 1-3, 5, 8-. Commas separate selections and a dash specifies a range.
  4. Run the tool and download the new PDF or ZIP file.

Verify the output

Open the downloaded file and check that the expected pages are present and in the right order. Page numbering printed on a page may differ from the PDF viewer's page index, so compare both when working with reports that have cover pages or front matter.

Privacy and limitations

The tool is designed to process supported files in your browser. Your browser downloads third-party code libraries to run the operation, but the file is not intentionally uploaded to a PDF Engine server. Encrypted, damaged or unusually complex PDFs may not work. Always keep the source file until the extracted result has been checked.

Use Split PDF to begin, or read the merge guide if you need to combine several documents first.
