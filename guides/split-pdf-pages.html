How to Split PDF Pages

A 200-page report rarely needs to travel as one file. Someone only wants chapter three, a printer needs the pages separately, or an upload form accepts a maximum of ten pages. Splitting is the answer in all of those cases, and the PDF Engine split tool offers two ways of doing it.

When to split a PDF

  • You need to send only part of a large document, such as one section of a contract.
  • A portal limits file size or page count, and the whole file is over the limit.
  • A scanned batch contains several different documents that should be filed separately.
  • You want each page as its own file, for example to attach individual receipts to expense lines.

If you only want one block of pages saved as a new document, Extract Pages does the same job with a simpler screen. Choose split when you also want the one-file-per-page option.

The two modes

Extract pages takes a page range and writes a single new PDF containing just those pages. Every page as separate PDF creates one PDF per page and delivers them together in a ZIP archive. The ZIP is built in your browser, so a 40-page document produces 40 small files in one download, named after the original with the page number added.

Step by step

  1. Open the Split PDF tool and add your PDF.
  2. Pick a mode. For a partial document, leave Extract pages selected.
  3. Type the pages you want in the range box. Examples: 1-3 for the first three pages, 1-3, 5 for those plus page five, 8- for page eight to the end.
  4. Click Split PDF. The result shows how many of the total pages were extracted and downloads as yourfile-extracted.pdf, or as a ZIP in the per-page mode.

How the page ranges are read

Numbers are separated by commas and ranges use a hyphen. An open end such as 8- means "to the last page". Typing all or leaving the box empty selects every page. If you type a range backwards, like 5-3, the tool treats it as 3 to 5. Pages mentioned twice are included once. A page number larger than the document, or a typo such as 1..3, produces an error message instead of a half-correct file, which is better than silently dropping pages. When extracting, the pages are written in the order you list them, so 5, 1-2 yields page five first.

Common mistakes

  • Counting printed page numbers instead of PDF page numbers. If a book starts its numbering after a cover and contents pages, "page 1" in print may be page 7 in the file. The tool counts physical pages from the first one.
  • Expecting the original to change. Splitting never edits your source file. Delete or archive it yourself if you no longer need it.
  • Splitting a signed or protected document and treating the pieces as signed. The pieces are new files.
  • Not checking where a section ends. A chapter's last paragraph sometimes spills onto the next page. Open the result and read the final page.

Quality and limits

Split copies the selected pages without recompressing them, so text stays sharp and selectable. File size drops roughly in proportion to the pages kept, though shared resources such as fonts can make a small extract a little larger than you expect. Very large files depend on your device memory. For encrypted PDFs that need a password, the tool cannot help. In per-page mode, remember that a 500-page file creates 500 files, which is rarely what anyone wants to open; extract a range instead.

Check the result

Open the new file and confirm the page count matches what you typed. Compare the first page against the original to make sure you started where you meant to. If the result is for email or an upload form, check its size and read how to get a PDF under upload limits.

A realistic example

You have a 48-page lease with a four-page schedule at the end, and the agent only wants the signed schedule. Open the file, scroll to the schedule, and note that it runs from page 45 to page 48. Choose Extract pages, type 45- and run the tool. Because the range is open-ended, it works even if you are unsure whether there are 48 or 49 pages. Name the result "lease-schedule-signed.pdf", open it, and check that the first page is the schedule heading rather than the last page of the main agreement.

Short FAQ

Can I split by bookmark or by every N pages?

Not directly. Type ranges such as 1-10, then 11-20, and run the tool once for each block.

Why is the ZIP not opening on my phone?

Some phone file managers need an extra step to unzip. Save it to your device and open it from the Files app, or use a computer.

Is anything sent to a server?

No. The pages are copied in your browser. See PDF privacy before you share for the details.
