How to Merge PDF Files

Merging PDFs is useful when a report, application, set of invoices, or scanned document has been saved as several separate files. Combining them can make the result easier to review and share, but it is worth preparing the files before you merge.

Before you start

  1. Find every PDF that belongs in the final document.
  2. Rename files or make a short list so the intended order is clear.
  3. Open each file and confirm it is the correct version, especially if it contains signatures or updated pages.

Merge the documents

  1. Open the Merge PDF tool.
  2. Select at least two PDF files from your device.
  3. Use the move-up and move-down controls to arrange the order.
  4. Run the merge and download the new PDF.

Check the result

Open the merged file and inspect the first and last pages of each source document. Check page orientation, blank pages, page count and any forms or signatures that matter to your workflow. Keep the original PDFs until you have confirmed the combined file is complete.

Privacy and limitations

PDF Engine's merge operation is designed to process files in the browser instead of uploading them to a document-processing server. Your browser still downloads the JavaScript libraries needed for the tool. Very large, encrypted or unusual PDFs may fail, and some advanced interactive features may not be preserved by every PDF library. If a document is sensitive or legally important, verify the result in a trusted PDF reader before using it.

Try it

Use Merge PDF to combine supported documents. For a few pages from a large file, the Split PDF tool may be a better fit.
