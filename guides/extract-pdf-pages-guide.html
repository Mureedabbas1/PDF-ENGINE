Extract PDF Pages: A Practical Guide

Extracting pages means making a new PDF out of a selection from an existing one. It is what you do when you need page 14 of a contract, the invoice buried in a 60-page statement, or the two pages of a manual that your colleague actually needs. The result is a smaller, focused file that is easier to send and harder to misread.

When extraction is the right choice

  • Sharing one section of a long document without exposing the rest.
  • Attaching just the relevant pages to an email or support ticket.
  • Building a new document from pieces of several others (extract from each, then merge).
  • Saving form pages or certificates out of a big scanned batch.

The Split PDF tool offers the same extraction plus a mode that creates one file per page. Choose Extract Pages when you simply want the selection, with fewer options on screen.

Step by step

  1. Open the document in a viewer and note the page numbers you need.
  2. Open the Extract Pages tool and add your PDF.
  3. Type the pages into the range box. For example 1-3, 2, 7, 9 or 12- for page 12 to the end. Typing all copies every page.
  4. Click Extract pages. The tool tells you how many pages were extracted and saves yourfile-extracted.pdf.

The order of pages in the result

Pages are written in the order in which you list them, not in their original order. Entering 9, 2-3 produces a three-page file starting with page 9. That is a handy side effect when you want a cover or summary to come first, but it can surprise you if you list numbers casually. A range typed backwards is corrected, so 6-4 becomes 4 to 6. Duplicate numbers are collapsed, so each page appears once, and numbers outside the document cause an error message instead of a partial result.

Choosing page numbers reliably

PDF viewers show a page counter such as "14 / 60". That number is the one the tool uses. Printed numbers can differ if the document has a cover, roman-numeral front matter or sections numbered separately. When in doubt, scroll to the page in the viewer and read the counter rather than the number printed in the footer. For long documents, note the first and last page of the section you want, since a section's final page often contains only a few lines.

Common mistakes

  • Extracting too tightly. A table or paragraph that continues onto the next page will be cut off. Include the following page if the content runs over.
  • Forgetting related pages. An attachment may refer to a definitions page or schedule that is somewhere else in the document.
  • Assuming the extract is private. Check that the extracted pages do not include a header or footer with information you meant to hold back, and read PDF privacy before you share.
  • Not renaming the file. The default name is fine for you, but a recipient expects something descriptive such as "lease-agreement-signature-page.pdf".
  • Treating an extract of a signed file as signed. Signatures belong to the original file.

Quality and limits

Pages are copied rather than re-rendered, so text stays selectable and image quality is unchanged. Small extracts from a large document are generally much smaller than the source, although fonts and shared images can add some overhead. A password-protected file cannot be opened by the tool. If the file you need is very large, give the browser a moment, because the whole document has to be read in memory before pages are copied. Hyperlinks inside the extracted pages that point to other pages of the original will no longer lead anywhere useful, so test links if they matter.

Check the result

Confirm the page count, then read the first and last page. If you extracted several ranges, make sure the join between them looks right. If the extracted pages need to go into a larger document, continue with the merge guide. If you would rather delete pages than select them, use the remove pages guide.

A realistic example

A 90-page bank statement contains one page with the transaction a landlord asked to see, plus the account summary on page 1. Type 1, 63 to produce a two-page file with the summary first and the transaction page second. Before sending, read both pages for unrelated transactions or personal details that were not requested, since a statement page is rarely limited to the line you care about. If there is too much unrelated detail, ask whether a different document would serve the purpose better.

Short FAQ

Does extracting change the original file?

No. A new file is created.

Can I extract from a scanned document?

Yes. Scanned pages are images, and they are copied as they are. See scanned vs text PDFs.

What is the maximum number of pages?

There is no limit set by the tool; your device's memory is the practical limit.
