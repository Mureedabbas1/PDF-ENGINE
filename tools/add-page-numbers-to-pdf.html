About Add Page Numbers

Page numbers make long documents like reports, theses and manuals easier to read and reference. Choose where the number appears, pick a style such as Page 1 of 10, and optionally skip the cover page.

When it is useful

Page numbers make reports, manuals, study notes and long documents easier to reference.

Important limitations

Review the placement around footers and existing text. This tool adds visible text to pages; it does not infer printed page numbering already present.

Privacy and file handling

Good to know

Available formats include simple numbers and labels such as Page 1 of N. You can skip the first page.

Add Page Numbers to PDF: A Practical Guide

Page numbers make long PDFs easier to navigate, reference and print. They are helpful for reports, proposals, manuals, coursework, scanned records and meeting packs. A consistent position and style helps readers find their place without distracting from the document.

Plan the numbering scheme

Consider whether the cover page should be numbered and whether numbering should begin at 1 or continue from an earlier section. Printed page labels inside a document may differ from the physical page positions in the PDF. Check the tool's available starting-number and placement options before processing.

Add numbers and verify

Select the PDF, choose the supported numbering options and run the operation. Download the result and inspect the first, middle and final pages. Make sure numbers do not overlap footnotes, signatures, existing page labels or important content.

Printing considerations

Leave enough space from the page edge so numbers are not clipped by printers or hidden by binding. Review landscape pages separately because a footer position can look different on pages with another orientation.

Frequently asked question

Does page numbering create a clickable table of contents? No. Visible page numbers help readers reference pages, but they are not the same as bookmarks or navigational links.

Common questions about Add Page Numbers

Can I skip the cover page?

Yes. Tick Do not number the first page and numbering starts from the second page.

Can I start from a different number?

Yes. Change Start from number to any value you want.

Which formats are available?

You can use 1, Page 1, Page 1 of N or 1 / N.
