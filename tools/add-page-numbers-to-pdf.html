Add Page Numbers to a PDF

Add numbered labels with selectable positions, formats and start values.

Use the tool

Start the interactive tool on the main PDF Engine page. Selected files are processed in your browser for supported operations.

Open Add Page Numbers →

How to use Add Page Numbers

  1. Select a PDF file.
  2. Choose number position, format, and starting value.
  3. Generate and inspect the numbered PDF.

When it is useful

Page numbers make reports, manuals, study notes and long documents easier to reference.

Important limitations

Review the placement around footers and existing text. This tool adds visible text to pages; it does not infer printed page numbering already present.

Privacy and file handling

This tool is designed to process supported files locally in your browser; the static website does not provide server-side file storage. Your browser still downloads the JavaScript libraries required for some operations from third-party content delivery networks. See the Privacy Policy for details. Do not use the output without checking it, and keep your original file.

Frequently asked question

Available formats include simple numbers and labels such as Page 1 of N. You can skip the first page.
