How to use Split PDF

  1. Choose a PDF file.
  2. Select Extract pages or Every page as a separate PDF.
  3. Enter page ranges when extracting, then download the PDF or ZIP.

When it is useful

Split a long report into chapters, share one invoice from a batch, or separate scanned pages for individual review.

Important limitations

Use page numbers as shown by the PDF viewer, not necessarily the printed page labels. Large PDFs may require more memory, and password-protected files may fail.

Privacy and file handling

This tool is designed to process supported files locally in your browser; the static website does not provide server-side file storage. Your browser still downloads the JavaScript libraries required for some operations from third-party content delivery networks. See the Privacy Policy for details. Do not use the output without checking it, and keep your original file.

Frequently asked question

Page ranges accept formats such as 1-3, 5, 8-. The original PDF remains unchanged.

Split PDF: A Practical Guide

Splitting divides a large PDF into smaller files or individual pages. It is useful when different people need different sections, when an upload service has a file-size limit or when you want to archive pages separately.

Choose a split plan

Decide whether you need one file per page or several grouped page ranges. Identify physical page positions in the PDF viewer; printed page labels may not match the file's page count. Make sure you have enough device storage for all resulting files.

Run and inspect the split

Select the source PDF, choose the available split method and process it. Multiple outputs may be packaged in a ZIP archive. Extract the archive and open several files to confirm that the page sequence and filenames make sense.

Large document considerations

Splitting still requires the browser to read the source PDF. Very large or complex documents may need to be processed in smaller batches. If a split fails, keep the original and try a smaller range.

Frequently asked question

Does splitting delete the source? The split files are separate outputs. Retain the original PDF as your complete reference copy.
