Edit PDF Metadata: A Practical Guide

Metadata is descriptive information stored with a PDF. A useful title, author, subject and set of keywords can make a document easier to identify in file managers, libraries and document-management systems. Metadata is separate from the words and images visibly printed on the page.

Choose accurate document properties

Use a concise title that describes the file, an author or organisation name that is correct, and a subject that explains its purpose. Add only relevant keywords. Avoid unrelated terms or promotional phrases that do not describe the document.

Update and verify

Select the PDF, enter the fields you want to change and save the updated copy. Open the document properties in a PDF reader to confirm that the new values appear as expected. Leave fields unchanged when you do not know the correct information.

Metadata is not a privacy tool

Changing metadata does not remove visible names, comments, attachments, form values or other hidden content. Review a document separately before publishing it, especially if it came from an internal business workflow.

Frequently asked question

Will metadata appear on the PDF page? Usually it is shown in document properties rather than as visible page text. Keep the filename and visible document content clear as well.
