Edit PDF Metadata Online

Update a PDF's title, author, subject and keyword metadata.

Use the tool

Start the interactive tool on the main PDF Engine page. Selected files are processed in your browser for supported operations.

Open Edit PDF Metadata →

How to use Edit PDF Metadata

  1. Select the PDF file.
  2. Enter the metadata fields you want to change.
  3. Save and download the updated PDF.

When it is useful

Make document properties easier to identify in file managers, libraries and document-management workflows.

Important limitations

Metadata is not a security control. Existing visible text, comments, attachments and hidden content may remain unchanged.

Privacy and file handling

This tool is designed to process supported files locally in your browser; the static website does not provide server-side file storage. Your browser still downloads the JavaScript libraries required for some operations from third-party content delivery networks. See the Privacy Policy for details. Do not use the output without checking it, and keep your original file.

Frequently asked question

Only fields you enter are updated. Review document properties in a PDF reader after saving.
