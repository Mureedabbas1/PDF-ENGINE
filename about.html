About PDF Engine

PDF Engine is a free collection of browser-based tools for everyday PDF and image tasks. It is designed to make common document operations easy to understand without requiring desktop software or an account.

PDF Engine is an online web service that you use directly in a web browser; it is not a downloadable desktop software product. The website does not distribute a desktop application, software installer, browser extension, or plugin.

When a tool creates a downloadable file, that file is the result of your task—such as a processed PDF or image—not an installer for software.

Tools and use cases

Depending on file type and browser support, you can merge or split PDFs, extract or remove pages, reorder and rotate pages, add page numbers and text watermarks, crop pages, convert images to PDFs, export PDF pages as images, extract selectable text, and update metadata. Small utilities include a word counter, age calculator, image compressor and QR code generator.

How file processing works

Supported operations are performed in your browser. This static site does not provide a server-side document storage account. Some libraries and fonts are downloaded from third-party content delivery networks; those providers may receive normal connection information when your browser requests resources. Please read our Privacy Policy.

Quality and limitations

Files vary in structure, encryption, size and embedded content. Some operations may not support every PDF. Compression and grayscale tools can rasterize pages and remove selectable text; cropping changes the crop box and does not securely erase content hidden outside it. Always review the downloaded result and keep your original file.

Guides and feedback

Read our PDF guides for practical workflows. To report a bug or suggest an improvement, use the public GitHub issue tracker. Please do not post private documents or personal information in a public issue.
